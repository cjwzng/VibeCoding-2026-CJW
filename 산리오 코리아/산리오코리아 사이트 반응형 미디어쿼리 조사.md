# 산리오코리아 사이트 반응형 미디어쿼리 조사

업로드된 `style.css`, `style_dev.css`, `extend_a.css`, HTML 파일을 분석한 결과입니다. 바이코딩 교육용 훈련 참고 자료이며, 아래 사이즈는 코딩 요청이 아니라 변경 내용 파악용입니다.

## 먼저 알아둘 점

사이트의 실제 중단점은 계획한 값과 조금 다릅니다.

| 계획한 구간 | 사이트의 실제 값 |
| --- | --- |
| 1199px | **1199px** (헤더/메뉴/컨테이너, 거의 일치) |
| 1023px | **1024px** (사실상 같은 구간으로 보면 됩니다) |
| 800px | **800px**, 그 아래 **736px**에서 한 번 더 줄어듭니다 |

사이트에는 736px 구간이 추가로 있어서 800px 이하와 736px 이하를 나눠서 적었습니다. 클론할 때 736px 변경까지 필요하면 클로드에게 "800px 이하에 합쳐서" 또는 "736px도 별도로"라고 알려주면 됩니다. 767/768px(탭 메뉴 등)과 440/500px은 서브페이지 위주라 제외했습니다. 메인 페이지만 클론했다면 아래 내용으로 충분합니다.

## 파트별 변경 내용 (메인 페이지 기준)

### 1. 공통 컨테이너

- **1199px 이하**: 컨테이너가 고정 너비에서 가로 꽉 차는 형태로 바뀝니다. 좌우에 14px 여백만 둡니다.
- **767px 이하**: 기본 글자 크기가 87.5%로 줄어듭니다.

### 2. 헤더와 메뉴

- **1199px 이하**:
  - PC용 가로 메뉴가 사라지고 우측에 햄버거 버튼(너비 34px)이 나타납니다.
  - 버튼을 누르면 메뉴가 화면 전체를 덮는 흰색 패널로 오른쪽에서 슬라이드되며 나타납니다. 항목은 세로로 쌓이고 가운데 정렬에 대문자, 글자 크기가 큽니다(2.625rem).
  - 헤더 높이는 100px이고 아래에 회색 구분선이 생깁니다.
  - 메뉴 패널 하단에 페이스북 아이콘이 가운데 정렬로 놓입니다.
- **1024px 이하**: 로고 너비가 30%로 줄어듭니다.
- **736px 이하**: 헤더 높이가 50px로 줄고 햄버거 버튼은 24px로 작아집니다(선도 3px로 가늘어집니다). 메뉴 글자 크기는 28px이고 항목 간격이 좁아집니다.

### 3. 오른쪽 고정 버튼 (TOP, 퀵 버튼, SNS)

- **1024px 이하**: TOP 버튼은 오른쪽에서 30px, 퀵 버튼은 10px 떨어진 곳에 위치합니다. SNS 아이콘은 고정 배치되어 헤더 아래(top 112px)로 내려갑니다.
- **736px 이하**: SNS 아이콘 위치가 화면 너비 기준(20vw)이 되고 아이콘 크기는 34px로 작아집니다.

### 4. 메인 비주얼(슬로건)

- **1024px 이하**: PC용 슬로건 이미지가 숨겨지고 모바일용 이미지가 나타납니다. 좌우 여백은 30px입니다.
- **736px 이하**: 좌우 여백이 없어지고 두 번째 슬로건 이미지는 너비 70%로 줄어듭니다. 아래 스크롤 버튼은 하단에서 20px 위로 올라옵니다.

### 5. 섹션 공통

- **800px 이하**: 섹션 상하 여백이 75px로 줄어듭니다.
- **736px 이하**: 섹션 여백은 50px로 더 줄고 섹션 제목 글자는 2.33rem으로 작아집니다.

### 6. character (캐릭터 목록)

- **800px 이하**: 캐릭터 카드가 2열로 바뀝니다. 한 줄에 2개씩 나오고 카드는 정사각형이며 이미지는 카드 중앙에 놓입니다.
- **736px 이하**: 캐릭터 이름 영역 높이가 줄어듭니다.

### 7. 두 번째 영역: SNS 피드(페이스북)

- **1024px 이하**: 피드 영역 최소 높이가 650px입니다.
- **850px 이하**: 피드 항목 높이가 500px입니다.
- **800px 이하**: 피드가 한 줄씩 나오고(100%) 영역 아래 여백이 150px입니다. 배경 이미지는 90% 크기가 됩니다.
- **736px 이하**: 항목 높이가 400px로 줄고 전체 높이는 900px입니다.
- **767px 이하(style\_dev.css)**: 항목 3번째부터 숨기고 처음 2개만 보여줍니다.

### 8. company (회사 소개 4개 아이콘)

- **800px 이하**: 4개 항목이 2×2 배치로 바뀝니다. 항목 사이에 회색 선이 들어가고 오른쪽 세로선은 제거됩니다. 위 2개와 아래 2개 사이에는 5% 여백이 생깁니다.
- **736px 이하**: 항목 너비가 50%이고 아이콘은 35% 크기로 줄어듭니다.

### 9. recruit (채용 3개 항목)

- **1024px 이하**: 배경 이미지가 PC용에서 태블릿용으로 교체되고 좌우 여백이 9%입니다.
- **800px 이하**: 배경이 모바일용 이미지로 교체됩니다(90% 크기, 상단 30px). 각 항목이 가로 배치(아이콘 57% + 텍스트 33%)로 바뀝니다.
- **736px 이하**: 아이콘 52%, 텍스트 48%로 비율이 바뀌고 더보기 버튼도 작아집니다(최대 80px).

### 10. place / shop 영역 (row5)

- **1024px 이하**: 배경 이미지가 태블릿용으로 교체됩니다.
- **800px 이하**: 배경이 모바일용 이미지로 교체되고 cover로 채웁니다.
- **736px 이하**: 상하 여백이 55px입니다.

### 11. contact us / 지도 (row6)

- **1024px 이하**: 아래 여백이 150px로 커지고 스티커 이미지는 오른쪽 40px, 아래 -120px 위치가 됩니다.
- **800px 이하**: 지도 높이가 280px이고 위쪽 모서리가 둥글어집니다(20px). 주소 글자는 10px입니다.
- **736px 이하**: 지도 높이가 150px로 줄고 스티커는 너비 40%, 오른쪽 10px, 아래 -40px이 됩니다. 연락처 글자는 0.9rem입니다.

### 12. 푸터

- **800px 이하**: 가로로 배치되던 푸터가 세로로 쌓입니다(block). 저작권 영역은 100% 너비에 가운데 정렬이고 모바일용 메뉴 버튼이 나타납니다. PC용 요소는 숨겨지고(`pc_ver`) 모바일용(`m_ver`)이 보입니다.
- **736px 이하**: 푸터 여백이 30px / 50px이 되고 저작권 이미지는 60%로 줄어듭니다.

### 13. 공통 열 레이아웃 (`col2`, `col3`, `col4`)

- **800px 이하**: `col2`와 `col3`는 100% 너비로 한 줄씩 나옵니다. `col4`는 2열(48.5%)입니다.

## 다음 단계

내 사이트에는 박스 이름이 다르니 이렇게 진행하면 좋습니다.

1. 위 내용을 **파트 이름만 내 박스 이름으로 바꿔서** 정리합니다. 예: "main\_row3 → 내 company 영역"
2. 클로드에게는 **내 HTML/CSS + 위 설명**을 같이 넣고 요청합니다.
3. 요청할 때 "PC 기본 CSS는 수정하지 말고, 아래에 `@media (max-width: 1199px)`, `1024px`, `800px`, `736px` 순서로 추가해 줘"라고 순서를 지정하면 정확합니다.
