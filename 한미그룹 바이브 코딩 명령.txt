[작업 요청: '회사 복지' 신규 섹션 마크업 및 반응형 CSS 구현]

1. 섹션 위치 및 구조
- 기존 HTML의 <main> 영역 내 다섯 번째 섹션인 '.innovation' 바로 다음 형제(sibling)로 새로운 <section class="welfare">을 추가해 줘.
- 섹션 내부는 시맨틱 태그 구조를 준수하고, 기존 HTML/CSS의 네이밍 컨벤션과 일관성을 유지해 줘.

2. 반응형 디자인 및 미디어쿼리 (첨부 이미지 3종 매칭)
- 첨부된 첫 번째 3개 이미지(순서대로 데스크톱, 태블릿, 모바일)를 정밀 분석해 줘.
- 각 뷰포트별 요소의 배치, 폰트 크기, 간격(margin/padding), 정렬 변화를 추적하여 CSS 미디어쿼리(Desktop / Tablet / Mobile)를 체계적으로 작성해 줘.

3. 카드 레이아웃 및 스크롤 영역 구현
- 메인 카드 영역은 데스크톱 기준 5행 2열(총 10개)이 기본 뷰포트에 보이도록 배치해 줘.
- 카드 컨테이너에 적절한 높이(또는 최대 높이)와 `overflow-y: auto`를 적용해 줘.
- 기본으로 노출되는 10개 카드 외에, 스크롤을 내렸을 때 동일한 카드가 반복되어 추가로 노출되도록 총 20개의 카드 마크업을 구성해 줘.
- 스크롤바 트랙과 썸(Thumb)은 화면 덤프처럼 폭이 얇고 세련된 디자인으로 커스텀 스타일링해 줘 (::-webkit-scrollbar 및 표준 scrollbar-width 속성 지원).
- 태블릿 및 모바일 미디어쿼리 전환 시에도 화면 덤프와 일치하도록 열 수(Grid column) 및 스크롤 영역의 높이/레이아웃을 자동 조정해 줘.

4. 이미지 경로 및 에셋 처리
- 화면 덤프에 들어가는 모든 이미지 에셋은 `./images/` 폴더 기준으로 상대 경로를 지정해 줘 (예: `./images/welfare_card_01.jpg`).
- 이미지 태그에는 직관적인 `alt` 텍스트를 반드시 포함해 줘.
