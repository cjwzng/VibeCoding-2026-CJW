HTML·CSS·JavaScript 파일 분리
화면 본문
[학습 개요]
동작을 확인한 페이지의 구조·스타일·기능을 분리하고, 초기화와 공통 스타일을 다른 페이지에서 재사용할 수 있게 정리합니다.
파일별 역할
index.html: 문서 구조와 콘텐츠
reset.css: 초기화 규칙
common.css: 글꼴·공통 레이아웃·제목·버튼·헤더·푸터
main.css: 메인 페이지 전용 영역과 배너 스타일
common.js / main.js: 공통 메뉴 기능과 메인 배너 기능
분리할 때 확인할 사항
CSS 순서와 미디어쿼리 우선순위를 유지합니다.
CSS 이미지 경로를 새 파일 위치에 맞게 수정합니다.
기존 style·script와 새 파일을 중복 실행하지 않습니다.
페이지 전용 요소가 없는 곳에서는 JS를 실행하지 않도록 확인합니다.
실습 및 산출물 (Practice & Deliverables)
Target Area: 프로젝트 전체 파일
산출물: 역할별로 분리한 HTML·CSS·JS
달성 기준: 파일을 분리하기 전후의 화면과 기능이 동일합니다.
